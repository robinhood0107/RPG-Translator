# 개발·검증 수치 기록

기록 범위는 공통 번역 도구의 구현·검증 지표다. 특정 게임의 대사·등장인물·줄거리·화면 내용·원문·번역문·게임 파일명은 기록하지 않는다. 기능상 필요한 번역 DB와 원본 데이터는 이 보고서의 출력 대상이 아니다.

재수집 가능한 원본 수치는 `verification-metrics.json`에 저장한다. 수집기는 DB를 읽기 전용으로 열고 집계 쿼리만 실행한다.
